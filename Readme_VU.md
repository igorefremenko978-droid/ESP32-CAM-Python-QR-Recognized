# ESP32-CAM QR Scanner
<img width="902" height="732" alt="image" src="https://github.com/user-attachments/assets/4973bb57-1dec-48ae-ad5d-f4be2488a795" />

Десктопное приложение для захвата кадров с камеры ESP32-CAM по HTTP, распознавания QR-кодов и отображения результатов в реальном времени. Написано на Python с использованием PyQt6, OpenCV и pyzbar.

## Возможности

1. **Захват кадра по HTTP** с ESP32-CAM (эндпоинт `/capture`).
2. **Распознавание QR-кодов** на кадре через pyzbar + OpenCV.
3. **Ориентация QR не важна** — pyzbar находит и декодирует QR-коды в любом положении относительно камеры (поворот, наклон, зеркальное отражение в разумных пределах). Специальная предобработка (поворот изображения, выравнивание) не требуется.
4. **Несколько QR на одном кадре** — за один снимок обрабатываются все найденные коды. Каждый распознанный текст выводится отдельной строкой в лог, а на изображении отрисовываются рамки вокруг всех найденных QR.
5. **Управление подсветкой (вспышкой) ESP32-CAM**: включение/выключение и регулировка яркости (0–255).
6. **Два режима работы**: ручной и автоматический.
7. **Лог** с отметками времени и возможностью копирования.
8. **Настройка подключения** (IP-адрес и порт камеры) через диалоговое окно.

## Особенности работы

### Подключение к камере
<img width="302" height="232" alt="image" src="https://github.com/user-attachments/assets/d2e502ec-312f-432b-b9e5-1ef234218ad2" />

Приложение общается с ESP32-CAM по HTTP. Адрес задаётся в меню **Настройки → Подключение...**:

- IP-адрес камеры (по умолчанию `192.168.88.206`);
- порт (по умолчанию `80`).

После сохранения настроек создаётся новый клиент и выполняется проверка доступности камеры (запрос к `/`). Результат проверки сразу отображается в логе:

- `✅ Камера доступна.` — камера отвечает;
- `❌ Ошибка подключения. Проверьте IP в настройках.` — камера недоступна.

Все сетевые запросы имеют таймаут 5 секунд, чтобы приложение не зависало, если ESP32 не отвечает.

### Режимы работы

**Ручной режим** — основной. Каждый снимок выполняется по нажатию кнопки «📷 Сделать снимок». Последовательность действий:

1. Если включён чекбокс подсветки — отправляется команда на включение LED с заданной яркостью.
2. Выдерживается пауза ~0,3 с, чтобы камера адаптировалась к освещению (экспозиция).
3. Запрашивается кадр (`/capture`).
4. Подсветка выключается.
5. Кадр декодируется, выполняется поиск QR-кодов, изображение с рамками отображается в окне, результаты пишутся в лог.

**Автоматический режим** — включается чекбоксом «Включить авто-сканирование». Приложение выполняет ту же последовательность автоматически с заданным интервалом (1–60 секунд, по умолчанию 3 с). Первый снимок делается сразу после включения режима. Кнопка ручного снимка на время авто-режима блокируется. Изменение интервала на лету перезапускает таймер с новым значением.

### Лог и работа с ним

Каждое событие в логе снабжается отметкой времени в формате ЧЧ:ММ:СС:

```text
[14:32:07] 🟢 QR: https://example.com
[14:32:07] 🟢 QR: TEXT-002
[14:32:10] ⚪ QR-код не найден.
```

Лог доступен для копирования:

- можно выделить отдельные строки (или их фрагменты) и скопировать через контекстное меню или `Ctrl+C`;
- можно выделить весь лог целиком (`Ctrl+A`, затем `Ctrl+C`) и вставить в любой внешний документ (Word, Excel, блокнот и т.п.).

Это удобно для последующей обработки результатов распознавания, ведения отчётов и архивирования.

## Архитектура проекта

```text
QR_Scanner_Project/
│
├── main.py                 # Точка входа
├── requirements.txt        # Зависимости
│
├── core/                   # Логика и сеть
│   ├── __init__.py
│   ├── camera_client.py    # HTTP-клиент ESP32-CAM
│   └── qr_processor.py     # Декодирование кадра и поиск QR
│
└── ui/                     # Интерфейс
    ├── __init__.py
    ├── main_window.py      # Главное окно
    └── settings_dialog.py  # Диалог настроек подключения
```

### core/camera_client.py

Класс `CameraClient` — тонкая обёртка над HTTP API ESP32-CAM:

- `check_connection()` — проверка доступности (GET `/`);
- `capture_frame()` — получение JPEG-кадра (GET `/capture`);
- `set_led(state, brightness)` — управление подсветкой (GET `/led?state=on|off&brightness=N`).

Хранит `ip` и `port` как атрибуты, чтобы диалог настроек мог их прочитать.

### core/qr_processor.py

Статический метод `QRProcessor.process_frame(image_bytes)`:

- декодирует JPEG в BGR-изображение OpenCV;
- ищет все QR-коды на кадре через `pyzbar.decode`;
- текст декодируется как UTF-8 с fallback на latin-1;
- на изображение наносятся зелёные рамки вокруг найденных кодов;
- возвращает `(img_bgr, qr_data, rects)`.

### ui/main_window.py

Главное окно: левая часть — изображение, правая — панель управления (ручной/авто-режим, подсветка, яркость, интервал) и лог. Содержит логику последовательности «вспышка → снимок → выключение → распознавание».

### ui/settings_dialog.py

Диалог ввода IP и порта с валидацией диапазона порта (1–65535).

```bash
python -m venv venv

```

## Зависимости

```text
PyQt6
requests
opencv-python
pyzbar
Pillow
```

**Важно:** opencv-python и numpy должны быть совместимы по ABI. Если при запуске возникает ошибка `numpy.core.multiarray failed to import`, установите `numpy<2` либо обновите opencv-python до версии, собранной под NumPy 2.x.

## Системные требования

- Python 3.10+ (рекомендуется 64-бит);
- Windows / Linux / macOS;
- для pyzbar на Windows может потребоваться установленная библиотека zbar (обычно ставится вместе с колесом).

```bash
python main.py
```

## API камеры (ESP32-CAM)

Приложение использует следующие эндпоинты прошивки:

| Метод | Путь                             | Назначение                        |
|-------|----------------------------------|-----------------------------------|
| GET   | `/`                              | Проверка доступности              |
| GET   | `/capture`                       | Получить JPEG-кадр                |
| GET   | `/led?state=on\|off&brightness=N`| Управление подсветкой             |
| GET   | `/settings`                      | Веб-настройки камеры (браузер)    |

Состояние подсветки на стороне ESP32 не сохраняется в NVS — это оперативный параметр. После перезагрузки камеры подсветка всегда выключена.
